# Wissensordner

Dieser Ordner ist Obsidian-kompatibel: normale Markdown-Dateien, interne Links und klare Dateinamen.

## Struktur

- `00-index.md` - Einstieg und Karte des Wissens.
- `projects/` - Projektkontext, offene Fragen, Arbeitsnotizen.
- `decisions/` - Entscheidungen mit Datum und Begruendung.
- `prompts/` - wiederverwendbare Prompts und Agentenanweisungen.

## Schreibregel

Eine Notiz soll genau einen Zweck haben. Wenn eine Entscheidung getroffen wird, kommt sie nach `decisions/`. Wenn ein Prompt wiederverwendbar ist, kommt er nach `prompts/`.
